# Les Brutes de Décoffrage · maquette

Maquette du site de Les Brutes de Décoffrage (maçonnerie, rénovation, pierre sèche, RGE), Saint-André-de-Majencoules (30).

En ligne : https://rovia-demos.github.io/les-brutes-de-decoffrage/

Site statique : `index.html`, `assets/css/style.css`, `assets/js/main.js`. Polices hébergées dans `assets/fonts/`. Page non indexée (`noindex` + `robots.txt`).
